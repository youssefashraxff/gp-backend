# Web search comparison: Serper v1 and v2

Date: 2026-11-27 · Tool: Serper (Google Search API) · Compared with: Tavily v1, Tavily v3
Status: **Serper v2 is the best result so far and the proposed design for the Market agent**,
pending a relevance check.

## Summary

Serper v2 runs the same 3-search design as Tavily v3 (Arabic restricted, English restricted,
English open), but restricts with Google's `site:` operator instead of Tavily's
`include_domains`. It returns **15.7 citable results per question, 5× Tavily v3**, with
**no empty searches**, **dates on 63% of results**, and identical results across runs.

## What was run

| Run | Searches per question | Calls |
|---|---|---|
| Serper v1 | English open (`hl en`) + Arabic open (`hl ar`), both `gl eg`, merged | 12 × 2 × 2 = 48 |
| Serper v2 | English open + Arabic query restricted to 10 Arabic sites + English query restricted to 10 English sites, merged | 12 × 3 × 2 = 72 |

**Arabic sites:** youm7, almasryalyoum, elwatannews, masrawy, ahram.org.eg, almalnews,
alborsaanews, amwalalghad, aqarmap, sis.gov.eg.
**English sites:** egypttoday, dailynewsegypt, egyptindependent, enterpriseam, zawya,
propertyfinder.eg, savills.com.eg, jll, knightfrank, mped.gov.eg.

All runs scored with the updated source lists (134 Egyptian + 83 international sites).

## Weaknesses

1. **"Citable" means a trusted site, not a relevant result.** A rough check: 77–78% of the
   restricted results mention the place by name (Sokhna/Galala or Obour), against 86% for the
   open search. Some restricted results are about Egypt in general, e.g. "IMF Board approves our
   fourth review" for the Sokhna market-size question. Relevance still needs checking.
2. **Some results are old.** Dates go back to 2016–2019 (e.g. a 2017 Daily News Egypt article
   for Obour prices). For market facts, the agent must check the date before using a result.
3. **Prices are still weak for Sokhna** (6 citable). The 10 sites per language are mostly news;
   price questions need listing sites.
4. **A Google redirect link** (`google.com/goto?...`) appeared in one result and should be
   resolved to the real URL.
5. **3 calls per question.** Cheap on Serper, but it uses half of the Market agent's current
   6-call limit for one question.

## What was learned

- **Restricting to known sites is what brings citable sources.** It failed on Tavily only because
  of Tavily's ~3-second limit on restricted searches. On Google it works reliably.
- **Google gives dates.** That matters for the evidence rule (every fact needs a source and a
  date).
- **The open search is still needed.** It finds local sources outside the lists, especially for
  New Obour City.

## Next

1. **Relevance check:** fill in `relevant` for one run per query, or have a cheap LLM rate each
   result (on the right place? answers the question?). This turns "citable" into "useful".
2. **Freshness:** test a date filter (Google's `tbs` time range, via Serper) on the restricted
   searches only, so official documents like Vision 2030 aren't cut.
3. **Site groups per question type:** listing sites for price questions, official sites for
   strategy questions, news sites for the rest.
4. **Resolve redirect links** in the Serper normaliser.
5. **Then close the tool comparison:** record Serper v2 as the web search design in spec 6.2,
   and move to the X2 experiment proper (model + prompt writing the queries).
