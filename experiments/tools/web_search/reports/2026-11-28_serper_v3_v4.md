# Web search comparison: Serper v3 (site groups) and v4 (date filter)

Date: 2026-11-28 · Tool: Serper · Compared with: Tavily v1, Tavily v3, Serper v1, Serper v2
Status: **neither version wins everywhere.** The best design is v3's site groups plus the date
filter only for the question groups where freshness matters (proposed serper_v5).

## What changed

All runs were rescored with the new code-based relevance check (`score.py`):
- a result is **relevant** if its title, snippet or URL mentions the place (e.g. Sokhna/Galala,
  Obour) **and** a keyword of the question's topic, in Arabic or English;
- **relevant citable** = relevant and from a citable site;
- **fresh** = dated within the last 24 months.

| Version | Change |
|---|---|
| Serper v3 | v2 + site lists per question group (news, prices, supply, strategy fit) |
| Serper v4 | v3 + Google date filter (last 24 months) on the two site-restricted searches only |

**Run:** 1 run each (Serper gave identical results across runs in v1 and v2), 12 × 3 = 36 calls
per version.

## Findings

1. **Site groups (v3) help a little overall (13.4 → 14.0)**, mostly where the lists changed:
   prices (17 → 20) and supply (16.5 → 18). Listing pages are often undated, so the undated
   share went up.
2. **The date filter (v4) works as intended:** old results drop from 12% to 2% and fresh rise to
   78%. But it costs relevant citable results (14.0 → 12.2), mainly in **supply** (−5.5) and
   **strategy fit** (−2). Hotel counts and Vision 2030 plans often come from older pages that
   are still valid.
3. **Strategy fit is the weakest group** in every version (4.5–7 relevant citable). The official
   sites have few pages that name the specific place.
4. **The one empty search** is `sokhna_q1` English sites, in both v3 and v4. Because it repeats,
   these sites probably just have nothing for that query. It isn't flakiness like Tavily's.
5. **Serper v3/v4 against Tavily v3:** 2–2.5× more relevant citable results, and dated.

## Proposed final design: serper_v5

v3 site groups, with the date filter **on** for market_division, area_projects, prices and
demand_seasonality, and **off** for supply and strategy_fit. Serper results are stable, so v5
should equal v4 for the four filtered groups and v3 for the other two. Expected: about
15 relevant citable per question with most results fresh. One confirmation run is 36 calls.
